# Memm Emulator – releases

Installers and the update feed for **Memm Emulator**, a launcher that opens Android apps (APK) on
Windows and macOS using the official Android Emulator.

This repository contains **no source code** – only [Releases](../../releases). The app checks them for updates.

## Download

Open the [latest release](../../releases/latest):

- **Windows (x64):** `Memm Emulator-<version>-win-x64-setup.exe`
- **macOS (Apple Silicon):** `Memm Emulator-<version>-mac-arm64.dmg`

On first start the app downloads the Android Emulator and an Android system image directly from Google
(about 2.5 GB, once) after you accept Google's Android SDK License. These Google components are not
redistributed here.
